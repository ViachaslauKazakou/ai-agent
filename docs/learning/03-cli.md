# Этап 3. CLI без LLM

## Цель

Сделать приложение удобным консольным интерфейсом до подключения сети, LLM и
инструментов. На этом этапе приложение уже принимает конфигурацию через CLI,
умеет выполнить одноразовый prompt или открыть интерактивный REPL, но не делает
сетевых запросов и не изменяет файлы.

## Аргументы

| Аргумент | Значение по умолчанию | Назначение |
|---|---|---|
| `--model MODEL` | `demo-model` | имя модели в `Session` |
| `--working-dir PATH` | `.` | рабочая директория сессии |
| `-v`, `--verbose` | выключен | печатать конфигурацию и статус |
| `PROMPT` | отсутствует | одноразовый пользовательский prompt |

Примеры:

```bash
cargo run -- "Изучи структуру проекта"
cargo run -- --model local-model --working-dir /tmp/project --verbose "Покажи статус"
cargo run
```

Если передан `PROMPT`, программа сохраняет его как `Role::User`, печатает
разобранную конфигурацию в verbose-режиме и завершает работу. Ответа модели пока
нет — это намеренное ограничение этапа.

## REPL

Без позиционного prompt запускается синхронный цикл чтения stdin:

| Команда | Действие |
|---|---|
| `/help` | показать справку |
| `/status` | показать UUID, модель, директорию и размер истории |
| `/model NAME` | изменить модель с валидацией |
| `/clear` | очистить историю сообщений |
| `/exit`, `/quit` | завершить REPL |

Любая строка без начального `/` считается пользовательским prompt и добавляется
в историю сессии. Ошибка одного prompt не завершает REPL.

## Разделение ответственности

`clap` отвечает только за синтаксис аргументов. Модуль `cli.rs` не знает, как
работает LLM или инструменты: он возвращает структурированные значения. Работа
с `Session` находится в orchestration-коде `main.rs`. Благодаря этому будущие
LLM-провайдеры и tools не должны менять правила разбора CLI.

## Критерии завершения

- [x] CLI понимает `--model`, `--working-dir`, `--verbose` и prompt.
- [x] Работает одноразовый режим без LLM.
- [x] Работает синхронный REPL.
- [x] Поддерживаются `/help`, `/status`, `/model`, `/clear`, `/exit`, `/quit`.
- [x] Ошибка prompt не завершает REPL.
- [x] Нет сетевых запросов и операций записи файлов.
